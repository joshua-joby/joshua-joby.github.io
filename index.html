Adaptive Learning Quiz System

Python: random, collections, json

A practice quiz that notices what you get wrong and asks about it more often.

Why: Reviewing weak spots helps more than repeating what you already know, so the program does the sorting.

  • Generates randomized questions on topics the user picks, weighting selection toward subtopics with lower accuracy.
  • Tracks accuracy per subtopic with defaultdict and adjusts difficulty from rolling performance history.
  • Saves sessions and question banks in JSON so progress carries over between sessions.
  • Uses a modular design, so new question domains plug in without changing core logic.

Workout & Meal Tracker

Python: pandas, matplotlib, datetime

A personal log that turns daily entries into trends you can read at a glance.

Why: A single day of data says little, but a rolling average shows whether a habit is holding.

  • Stores workouts, calories, and macronutrients in pandas DataFrames for fast filtering and aggregation.
  • Charts weekly training volume and caloric surplus or deficit with matplotlib.
  • Computes rolling 7-day averages with datetime to show consistency over time.
  • Keeps all data local in CSV files, with no database required.

Smart File Automation Tool

Python: os, shutil, re, pathlib

A command-line tool that sorts and renames messy folders by rules you write.

Why: Moving files cannot be undone easily, so the tool shows its plan before it acts.

  • Walks directory trees with os and pathlib and applies user-defined sorting and renaming rules.
  • Uses regular expressions to pull dates, prefixes, and extensions out of file names.
  • Includes a dry-run mode that previews every change before any file moves.
